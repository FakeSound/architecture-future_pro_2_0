## Дополнительный эффект, не отражённый в TCO

Прямое сравнение стоимостей недооценивает целевую архитектуру. За рамками TCO остаётся:

| Эффект              | Описание                                                                                             |
|---------------------|------------------------------------------------------------------------------------------------------|
| **Новые продукты**  | Real-time финтех-продукты (кредитный скоринг онлайн, мгновенные платежи) недоступны на текущем стеке |
| **Масштабирование** | Выход в новые регионы требует горизонтального масштабирования, невозможного на on-premise            |
| **AI-диагностика**  | Потоковая обработка медицинских событий — основа для коммерциализации AI-сервисов                    |
| **Скорость вывода** | От идеи до production-фичи — недели вместо месяцев (независимые домены, CI/CD)                       |
| **Аналитика**       | Время аналитика на подготовку отчёта — часы вместо дней (self-service + near-real-time данные)       |
